# Product Overview

## 淘沙分析平台 (Taosha Analytics Platform)

A natural language to SQL AI+BI analytics platform that bridges the gap between business users and data analysis.

### Core Purpose
- Enables business users to query data using natural language without SQL knowledge
- Provides intelligent data analysis capabilities through LLM integration
- Reduces dependency on technical teams for routine data queries

### Key Features
- **Natural Language Queries**: Convert business questions to SQL automatically
- **Intelligent Workflows**: LangGraph-based conversational AI with human-in-the-loop validation
- **Multi-Service Modes**: 
  - Business report intelligence enhancement
  - Data team coding assistance  
  - Self-service business analytics
- **Enterprise Integration**: Seamless integration with existing data infrastructure (Spark, FineReport, etc.)

### Target Users
- Business analysts and domain experts
- Data development teams
- Decision makers requiring quick data insights

### Business Value
- Zero technical barrier for data access
- Faster response to changing business requirements
- Reduced workload on technical teams
- Democratized data analysis across the organization
