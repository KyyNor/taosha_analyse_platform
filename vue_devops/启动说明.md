# Vue 版本启动说明

## 前置要求

1. **Node.js**: 版本 >= 16
2. **包管理器**: npm 或 yarn
3. **后端服务**: 确保后端 API 服务在 `http://localhost:8000` 运行

## 快速启动

### 1. 安装依赖

```bash
cd vue_devops
npm install
```

或使用 yarn：

```bash
cd vue_devops
yarn install
```

### 2. 启动开发服务器

```bash
npm run dev
```

或：

```bash
yarn dev
```

应用将在 http://localhost:3000 启动

### 3. 构建生产版本

```bash
npm run build
```

构建文件将生成在 `dist/` 目录下

## 部署说明

### 静态文件部署
1. 运行 `npm run build`
2. 将 `dist/` 目录部署到Web服务器
3. 配置反向代理到后端API

### Docker部署
```dockerfile
FROM nginx:alpine
COPY dist/ /usr/share/nginx/html/
COPY nginx.conf /etc/nginx/conf.d/default.conf
```

### nginx配置示例
```nginx
server {
    listen 80;
    root /usr/share/nginx/html;
    index index.html;
    
    location / {
        try_files $uri $uri/ /index.html;
    }
    
    location /api/ {
        proxy_pass http://backend:8000/api/;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
}
```

## 问题排查

### 常见问题

1. **端口冲突**: 修改 `vite.config.ts` 中的端口配置
2. **API连接失败**: 检查后端服务是否运行在8000端口
3. **依赖安装失败**: 清除缓存后重新安装
   ```bash
   rm -rf node_modules package-lock.json
   npm install
   ```

### 性能优化建议

1. **路由懒加载**: 已实现，大型页面按需加载
2. **图片优化**: 使用WebP格式，启用懒加载
3. **缓存策略**: API结果缓存，减少服务器负载

## 技术支持

如遇到技术问题，请检查：
1. Node.js版本是否符合要求
2. 后端API服务是否正常
3. 浏览器控制台是否有错误信息
