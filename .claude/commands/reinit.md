# 从最近git提交总结更新CLAUDE.md文件

## 功能说明

此命令用于根据最新的git提交记录更新CLAUDE.md文档，确保项目文档与实际代码状态保持同步。

## 执行步骤

1. **检查基准点**：读取CLAUDE.md文件末尾的"Documentation Last Update"部分，获取上次更新的commitID
2. **获取变更范围**：使用`git log --oneline [基准commit]..HEAD`获取自上次更新以来的所有提交
3. **分析提交内容**：
   - 逐个分析提交信息和变更内容
   - 按功能模块分类整理（Backend/Frontend/UI/Database等）
   - 识别重要的功能添加、问题修复和架构变更
4. **更新文档结构**：
   - 更新相应的功能组件描述
   - 在"New Features Since"部分添加新功能说明
   - 更新"Documentation Last Update"的commitID
5. **质量检查**：
   - 确保文档结构完整，语言通顺
   - 所有更新内容使用中文描述
   - 保持与现有文档风格一致

## 使用场景

- 🔄 **定期维护**：项目有重要功能更新后，定期同步文档状态
- 📝 **版本发布**：发布新版本前，确保文档反映最新功能
- 🆕 **新成员接入**：帮助新团队成员快速了解项目最新状态
- 📊 **项目回顾**：整理和总结项目发展历程

## 注意事项

- 更新前确保所有相关的代码变更已提交
- 重点关注用户体验相关的功能改进
- 保持文档的技术准确性和可读性
- 适当添加使用示例或配置说明（如需要）
