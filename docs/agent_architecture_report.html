Agent (实时助手)
实时交互
定位

面向日常数据查询的即时交互助手。通过自然语言对话，快速将用户问题转化为 SQL 查询，提供秒级的数据反馈。

核心架构
用户 (Web/Mobile)
↓
Next.js 前端 (Streaming)
↓
FastAPI 后端服务
↓
LangChain
NL2SQL
↓
DuckDB / Vector Store
关键能力
  • 自然语言转 SQL
  • 多轮对话上下文
  • 流式响应输出
  • 工具自动调用
查看技术细节

状态管理： 使用 LangGraph 管理对话状态，支持人机回环（Human-in-the-loop）确认模糊意图。

检索增强： 集成 BGE 向量模型，通过 RAG 技术增强对专有业务术语的理解能力。

前端实现： 基于 Vercel AI SDK 实现打字机效果的流式输出，提升用户感知的响应速度。

DeepAgent (深度分析)
深度思考
定位

面向复杂业务场景的自动化分析专家。能够自主拆解复杂问题，制定分析计划，执行多步推理，并生成图文并茂的分析报告。

核心架构
任务队列 (Queue)
↓
规划器 (Planner)
↓
代码执行
数据检索
↓
报告生成器 (Reporter)
关键能力
  • 任务自主拆解
  • Python 代码执行
  • 自我反思修正
  • 生成 HTML 报告
查看技术细节

异步处理： 采用任务队列机制，支持长时间运行的分析任务（Long-running tasks）。

沙箱环境： 代码生成与执行在隔离的 Python 沙箱中运行，确保系统安全性。

成果交付： 最终产出不依赖 CDN 的独立 HTML 报告，包含可交互图表，适合内网分发与汇报。

场景与能力对比

特性 Agent (实时助手) DeepAgent (深度分析)
响应模式 同步流式，秒级响应 异步处理，分钟级响应
交互方式 Chat (聊天窗口) Submit & Report (提交-报告)
任务复杂度 单一查询，简单逻辑 多步推理，复杂逻辑，探索性分析
主要产出 文本答案，简单数据表格 结构化分析报告 (含图表、代码)
容错机制 用户追问澄清 自主反思，自我修正错误
