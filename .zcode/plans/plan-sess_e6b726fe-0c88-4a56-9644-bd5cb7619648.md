## 第三部分：宽表同步各阶段耗时（仅日志，不落库）

### 3.1 封装计时上下文工具
**修改** `backend/services/fraudhunter/wide_table_service/sync_service.py`
- 在文件顶部加一个轻量计时辅助（不引入新文件，就近定义）：
```python
import time
from contextlib import contextmanager

@contextmanager
def _stage_timer(stage_name: str, wide_table_name: str, etl_date):
    start = time.perf_counter()
    try:
        yield
    finally:
        elapsed = time.perf_counter() - start
        logger.info(
            f"[阶段耗时] {stage_name} | wide_table={wide_table_name} "
            f"etl_date={etl_date} | 耗时={elapsed:.3f}s"
        )
```

### 3.2 在 `sync_wide_table()` 各阶段埋点（line 55-189）
用 `with _stage_timer(...)` 包裹各阶段调用。按现有代码逻辑分段：

- skipped 路径（line 87-92、96-101、135-142）各自加一条带 `skip_reason` 的轻量日志，说明在哪一阶段跳过

## 验证方式

1. **SQL 高亮**：启动前端，进入指标任务详情页（非编辑模式）、风控模型详情页、规则构建器，确认只读 SQL 带 SQL 语法着色。
2. **版本 diff**：编辑并保存一个指标任务 2 次以上 → 打开版本对比 → 确认左右并排显示新旧 SQL 差异（增删行带颜色）。
3. **同步耗时日志**：触发一次宽表同步（DS 或重新启用调度任务）→ 在 `backend/logs/` 搜索 `[阶段耗时]`，确认每个阶段都打印了耗时。
